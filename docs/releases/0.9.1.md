# hookguard 0.9.1

*2026-08-24 · PyPI: `pip install hookguard`*

## Added

- `--local`: scan a local directory of Solidity files with no network access
  (`hookguard scan ./contracts --local`)
- `--md`: markdown report output (drives the public scan-request bot)
- Graceful, actionable error when the GitHub API is unreachable
- Public scoring rulebook: [docs/SCORING.md](SCORING.md)

## Fixed

- Contract qualification now requires a *structural* `getHookPermissions`
  body — interface declarations no longer satisfy the check by accident

## Automation

- `registry-watch` workflow now also refreshes adoption metrics weekly and
  commits drift authored as the maintainer, filing a rolling drift-report issue
